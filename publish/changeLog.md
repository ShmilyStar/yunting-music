本版本修复「下载更新后装上去还是同一个版本、继续提示更新」的问题，并给更新流程补上安装包校验。

### 修复

- 更新下载完成后，先解析安装包自身的版本号：和目标版本不一致就丢弃并换下一个下载源，
  不再把旧包 / 错误包直接交给系统安装器（此前不校验，遇到缓存或 CDN 回源时会出现
  「下载安装完，版本没变」）
- 下载缓存文件名带上版本号和 ABI，不再复用固定文件名，避免上一次残留的安装包被当成本次结果
- 版本信息请求加时间戳绕开 CDN / 本地缓存，发版后不会按旧版本号比对
- 下载失败会在日志里记录实际下载地址与包内版本，便于排查

### 注意

- Android 安装包按 ABI 提供，绝大多数设备选 `arm64-v8a`
- 1.0.10 的安装包本身没有问题，但更新链路缺少校验，统一由 1.0.11 取代
- 从 1.0.9 / 1.0.10 可直接覆盖安装
