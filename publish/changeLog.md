本版本修复「更新下载后安装提示安装包损坏」的问题：下载改为先落 `.part` 文件，校验完整性与版本后再改名交给安装器。

### 修复

- 下载先写到 `.part`，校验「大小 = 服务端 Content-Length」且「包内版本 = 目标版本」后才改名为正式文件，
  安装器不会再拿到没写完 / 写坏的包（此前第一次安装提示「安装包损坏」，退出重进再下才好）
- 同一时间只允许一个下载任务，连点「是」不会再出现两个任务写同一个文件
- 同一个下载源失败后自动重试一次，再换下一个源（手机网络抖动 / 服务端提前断开很常见）

### 注意

- Android 安装包按 ABI 提供，绝大多数设备选 `arm64-v8a`
- 从 1.0.9 / 1.0.10 / 1.0.11 可直接覆盖安装
